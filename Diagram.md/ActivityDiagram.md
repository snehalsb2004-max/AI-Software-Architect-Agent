# Activity Diagram

## Purpose

The Activity Diagram illustrates the workflow of the AI Software Architect Agent.

### Workflow

1. User enters project idea.
2. Requirement Agent analyzes requirements.
3. Architecture Agent recommends architecture.
4. Database Agent creates schema.
5. API Agent generates REST APIs.
6. Documentation Agent creates the final report.
7. User downloads the report.
