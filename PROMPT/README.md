# AI Agent Prompts

This folder contains the prompt templates used by the AI Software Architect Agent.

Each prompt is designed for a specific AI agent responsible for a particular task in the software architecture planning process.

## Available Agents

- Requirement Agent
- Architecture Agent
- Database Agent
- API Agent
- Security Agent
- Documentation Agent
- Roadmap Agent

The prompts will be used by the Spring Boot backend to communicate with Large Language Models (LLMs) such as OpenAI GPT, Gemini, or Ollama.
